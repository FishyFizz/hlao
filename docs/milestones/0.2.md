# Milestone 0.2 — Addressable and observable

**Branch:** `milestone/0.2-addressable-observable`
**Baseline:** HLAO 0.1.0 (`e3ece99`)
**Source:** `FEATURE-REVIEW.md` (independent review, 2026-10-19).

## Theme

Make the existing five primitives usable by a person running several agents, without adding
any orchestration concept. Address things by name, report the truth about history and death,
and let an operator watch and operate a live supervisor.

## 0.2a — Addressing and truthfulness

- [x] Resolve a unique session name within the caller's scope (exact ID first, then exact
      name, then ID prefix; duplicate names are `ambiguous_id` with candidates).
- [x] `hlao rename <id> <name>` / `--clear`; names appear in spawn/send/cancel/close/permit/
      mode output.
- [x] Inject `HLAO_NAME` at spawn; `whoami` shows it.
- [x] Self-default the session target for `read`, `wait`, `cancel`, `close`, `permit` when
      `HLAO_SESSION_ID` is set. `send`, `mode`, and `rename` use `--self` because their first
      positional is ambiguous (message / mode / new name).
- [x] `wait` exits `3` when the awaited condition was not met because the session ended;
      `--until exit` still exits `0`. Human output includes the exit code/signal.
- [x] Tail reads report eviction (`truncated`, `earliestRetainedSeq`) and the human hint is
      always printed when history is incomplete.
- [x] JSON without `--raw` no longer carries `rawInput`, `rawOutput`, or `content`; human
      `--verbose` renders bounded tool payloads.
- [x] Failed/closed headers show `ended` and `exit`, not a bare pid.
- [x] Human read shows timestamps; the pending-permission header block is deduplicated.
- [x] `list` human output has a scope footer and marks the caller's own session.
- [x] First-turn text separates distinct agent messages on a message-id change.
- [x] Guardrails: reject extra positionals; reject flag-like values for path options;
      `help <unknown>` errors; `--no-color`; warnings for inert `--timeout`/`--since`;
      `send --prompt/--prompt-file`.

Tests: `tests/unit/render.test.ts`, `tests/e2e/addressing.test.ts`,
`tests/e2e/read-polish.test.ts`; 88 tests green (`npm run check` clean).

## 0.2b — Observability and operations

- [x] `read --follow` is a CLI-owned loop over `read` + one-shot `wait`; JSON emits one page
      per line. Stops on terminal state or Ctrl-C.
- [x] `spawn --wait` prints the handle before waiting (human; two-phase CLI assembly).
- [x] Long `send --wait`/`wait`/`spawn --wait` print a TTY progress line after 2s.
- [x] `hlao status` is a read-only probe; no autostart unless `--start`.
- [x] `hlao logs [--lines] [--follow]` reads the supervisor log directly.
- [x] `doctor` is non-mutating by default (`--start` opts in) and distinguishes installed
      from running; `agents` reads config locally and never autostarts.
- [x] `hlao config show|path|validate` (local, env values redacted).
- [x] `hlao reload` re-reads user config in the supervisor for new spawns only; live sessions
      are untouched. `doctor` warns when the supervisor's config hash differs from disk.
- [x] Supervisor log rotates by size while running.

Tests: `tests/e2e/operations.test.ts`, `tests/unit/logger.test.ts`; 97 tests green.

## 0.2c — Read polish

- [x] Tool payloads under `--verbose`; usage cost; plan truncation marker; `mode` error
      renders `id/name`; `not_found` suggests `hlao list`.
- [x] ANSI control sequences from agent text/titles/names are stripped from human output.
- [x] `agents` shows config file paths with middle-truncation.
- [x] `down` warns that sessions and history are lost; README troubleshooting section.
- [x] macOS CI job (or drop the macOS claim).

Tests: `tests/e2e/polish.test.ts`; full suite green.

## Acceptance

- `npm run check` clean; all tests green.
- Each new behavior has a test through the real CLI → supervisor → scripted ACP agent.
- The README and contracts describe the shipped behavior, not a future one.
- No supervisor-side recurring timer; every follow/watch loop is caller-owned.
