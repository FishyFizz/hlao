# Milestone 0.4 — The socket is the product

**Branch:** `milestone/0.4-socket-contract`
**Baseline:** HLAO 0.3.0 (`df3d426`)
**Source:** `FEATURE-REVIEW.md` P1 observation/operations items, re-scoped around the
client boundary.

## Theme

The supervisor's socket protocol is the product boundary. The bundled CLI is the reference
client; a future TUI, web dashboard, or MCP server is another client and must not require core
changes. Core owns session state, authority, and the wire. It owns nothing about presentation.

The final shape:

```
human  -> dashboard / TUI  --\
                              >-- socket protocol -> core (supervisor)
agent  -> CLI / MCP        --/
```

Rules this milestone makes explicit:

- A presentation client never extends capability by itself. If a client needs something that
  is not on the wire, the wire is extended deliberately, with versioning.
- The CLI may keep client-only sugar (`--jsonl`, human rendering, local `agents`), but every
  orchestration capability it uses must be reachable by any other client.
- The protocol version is `major.minor`: major for breaking changes, minor for compatible
  additions. Capabilities are feature-detected through `hello`.

## 0.4a — Protocol observation completeness

- [x] `backends.list` on the wire: `{ cwd? } -> { backends: BackendView[] }`, the same merged
      user/project/builtin view as local `hlao agents`. A non-CLI client must not reimplement
      config merging. Operator and session callers may use it; a scoped caller defaults to its
      own cwd.
- [x] `SessionView.usage`: the latest ACP `usage_update` snapshot
      (`used`, `size`, `cost`, `at`), or `null`. Updated by the `usage` event.
- [x] `sessions.read` filters: `types?: EventType[]`, `turn?: number`,
      `grep?: string` (case-insensitive literal over the event type and data JSON).
      Filters apply before the page limit and byte budget, so cursors stay meaningful.
- [x] `sessions.read` backward paging: `before?: number` (exclusive), mutually exclusive with
      `since`. The result gains `nextBefore: number | null`.
- [x] Filter and paging cursors advance past scanned events, not only returned events, so a
      filtered follower does not rescan the same non-matching range.

## 0.4b — Public contract

- [x] `contracts/protocol.md` is rewritten as a client-facing contract: layering, transport,
      token and scope semantics, versioning rules, capabilities, polling, methods, events,
      errors, and worked examples. The line "Both sides are HLAO code; there is no third
      party" is removed.
- [x] `hello` params accept an optional `protocolVersion`, and the result carries
      `protocolVersion: { major, minor }` and `capabilities: string[]`.
- [x] Major mismatch is `version_mismatch`. A newer minor is compatible; a client uses
      capabilities to decide which optional features are available.
- [x] Known capabilities: `backends.list`, `session.usage`, `read.filters`, `read.before`,
      `wait.multi`.
- [x] A conformance test speaks raw NDJSON to the supervisor without the CLI and exercises
      `hello`, `backends.list`, spawn, send, read, filtered read, multi-wait, permit, and
      close.
- [x] A dependency-direction test asserts core modules do not import `src/cli/*`.

## 0.4c — `sessions.wait` on a list of ids

No new "group" concept. The existing method accepts a list.

- [x] Params: exactly one of `sessionId: string` or `sessionIds: string[]` (1..100), plus
      `mode?: "any" | "all"` (default `any`), `until`, `since?`, `timeoutMs?`.
- [x] `any` resolves on the first target that satisfies; `all` resolves when every target
      satisfies.
- [x] A target that ends before satisfying `idle`, `permission`, or `change` is unsatisfied
      with reason `exit`. For `all`, that resolves the whole wait unsatisfied immediately.
- [x] `change` uses each target's `lastSeq` at call time as its baseline; `since` is rejected
      with more than one id.
- [x] Result keeps the aggregate `satisfied`, `reason`, `waitedMs`; adds
      `results: WaitTargetResult[]` in request order. A target that is not settled when the
      aggregate resolves is evaluated at that moment: satisfied if it meets the condition,
      otherwise `pending`. `session` remains for a single-id call.
- [x] All ids are resolved against the caller's scope before waiting; one forbidden or
      unknown id fails the whole request.

## 0.4d — CLI reference client

- [x] `hlao wait <id...> [--any|--all]`; single-id behavior and exit codes are unchanged.
- [x] `hlao read --type TYPE --turn N --grep TEXT --before SEQ --jsonl`; `--since` and
      `--before` are mutually exclusive; `--jsonl` emits one event object per line.
- [x] `hlao list --usage` shows the latest usage/cost and a footer aggregate. Currencies are
      not mixed in the total.
- [x] `hlao status` reports the protocol version and capabilities.
- [x] Local `hlao agents` stays local and non-mutating; a test asserts it matches
      `backends.list` for the same cwd.

## 0.4e — Documentation and release

- [x] ADR 0007 records the client boundary: core owns the protocol; clients are replaceable;
      the bundled CLI is the reference client.
- [x] `docs/architecture.md`, `README.md`, `contracts/cli.md`, `contracts/session.md`, and
      `CHANGELOG.md` describe the shipped surface.
- [x] Version 0.4.0. Full suite green; `npm run check` clean.

## Tests

`tests/unit/events.test.ts` (filters, cursors, backward paging), `tests/unit/protocol.test.ts`
(new params and version), `tests/unit/architecture.test.ts` (no core→CLI import),
`tests/e2e/wire-contract.test.ts` (raw NDJSON, no CLI), and
`tests/e2e/protocol-client.test.ts` (CLI filters, jsonl, multi-wait, usage).

## Out of scope

TUI/web dashboard, MCP server, `permit --all-pending`, `send --tree`, `@last`, `cancel --wait`,
`--quiet`, pager, shell completion, aliases, resume, tags. Each is either a client assembly or
a separate milestone.

## Acceptance

- A client written against `contracts/protocol.md`, using only the socket, can observe and
  control every session the operator can.
- No new supervisor-side recurring timer.
- No TUI layout, keybinding, or stack decision appears in core code or core docs.
