# Milestone 0.3 — Control, visibility, and honest diagnostics

**Branch:** `milestone/0.3-control-and-clarity`
**Baseline:** HLAO 0.2.0 (`3be3c78`)
**Source:** `FEATURE-REVIEW.md`, items not covered by milestone 0.2.

## Theme

Finish the operator affordances the review asked for without adding a scheduler, a store, or a
registry. Every new control is a supervisor method over existing state or a CLI assembly over
existing primitives.

## 0.3a — Diagnostics that do not mutate

- [x] A read-only probe never creates `HLAO_HOME` (`status`, non-start `doctor`).
- [x] `doctor` says adapter commands are "present", not "ready"; always reports the log path.
- [x] `doctor --probe` optionally starts each available adapter, completes ACP
      `initialize`/`session/new`, and closes it (opt-in; implies `--start`).
- [x] Spawn failures carry the adapter exit code/signal in the error details and human output.
- [x] A version mismatch between CLI and a running supervisor warns once per process.
- [x] `session.created` records name, requested mode, and env keys (never values).
- [x] P2 docs/polish: README help/version rows, global-flag caveat, `HLAO_DEBUG`.

Tests: `tests/unit/client.test.ts`, expanded `tests/e2e/operations.test.ts`.

## 0.3b — Live control, attribution, and the upward channel

- [x] `hlao policy [<id>] [allow|ask|deny]` reads or sets a live session's permission policy
      without a pending request. `permit --always` becomes sugar over it.
- [x] Mutating events record the real actor (`by: <session id>` or `"operator"`) for policy,
      permission, mode, config, cancel, close, and rename. Prompt events record `from`.
- [x] A child may `send` to its direct parent only. Reads, waits, cancel, close, and permit stay
      forbidden on ancestors; authority still follows visibility. ADR 0006.
- [x] `hlao queue <id>` lists queued prompts (bounded preview, sender, position, age).
- [x] `hlao queue drop <id> <position>` removes one queued prompt and settles it as cancelled.
- [x] `cancel --keep-queue` stops the active turn without discarding the backlog. ADR 0005
      amended; `cancel` keeps clearing the queue by default.
- [x] Queue events carry sender and a bounded text preview.

Tests: `tests/e2e/control.test.ts`.

## 0.3c — Provider options, dashboard, cleanup

- [x] `SessionView.configOptions` exposes ACP session config options; `config_option_update`
      updates them and records the actor.
- [x] `hlao option <id>` lists options; `hlao option <id> <key> <value>` sets one (booleans
      accept true/false). `spawn --config key=value` and `--model VALUE` shortcut the model
      category.
- [x] `list --wide` adds policy, mode, pending detail, turn age, and exit detail;
      `list --tree` indents by lineage; filters `--status`, `--backend`, `--root`, `--name`,
      `--pending`; `--sort created|activity`; `--cwd-prefix DIR`.
- [x] `list --watch` is a caller-owned redraw loop; `--json` emits one result per change.
- [x] `close --idle DUR | --failed | --root ID | --status S` with `--dry-run`; one CLI
      assembly over list + close. `--forget` removes terminal rows via `sessions.forget`.
- [x] `read --out FILE` writes the JSON result to a file while normal output continues.

Tests: `tests/e2e/dashboard.test.ts`; config options covered in
`tests/e2e/control.test.ts`.

## 0.3d — Maintenance (no behavior change)

- [x] Split `src/cli/main.ts` into command modules with shared context/help/render helpers.
- [x] Remove dead paths (`agents.list`), narrow module export surfaces, and keep every module's
      responsibility in its contract.
- [x] Re-run the full suite and the real-CLI acceptance assemblies; docs unchanged except
      where behavior did not move.

The CLI is now `main.ts` (dispatch), `context.ts` (identity, target resolution, output),
`args.ts`, `input.ts` (message/env parsing), `help.ts`, `render.ts`, and
`commands/{prompts,list,control,ops}.ts`. `main.ts` is 186 lines; no command module owns
orchestration state.

## Deferred

`resume`/ACP `session/load`, multi-ID `wait --any/--all`, tags, broadcast, MCP wrapper, shell
completion, schema introspection, PTY fallback, durable transcript store. Each is either a
product decision or outside the five primitives.

## Acceptance

- `npm run check` clean; all tests green; new behavior covered through the real CLI.
- No supervisor-side recurring timer; watch/follow loops are caller-owned.
- Contracts and README describe shipped behavior; ADR 0005 amendment and ADR 0006 exist.
